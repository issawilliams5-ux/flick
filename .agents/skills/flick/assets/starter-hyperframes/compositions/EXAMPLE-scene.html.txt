  Reference example — NOT rendered by Flick directly (the .txt extension
  keeps it out of the way). Copy this shape for each real scene file at
  compositions/<scene-id>.html, replacing test-scene/#title/etc. with the
  approved scene's id and content.

  Each scene is a full standalone HTML document — NOT a <template>-wrapped
  sub-composition. HyperFrames' `-c <file>` render flag substitutes this
  whole document for index.html; it does not mount a fragment into a host.

  several scenes into one continuous timeline, which is not what Flick
  wants — Flick renders each scene to its own independent MP4.)

<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <!-- Vendored locally so renders never depend on a live CDN fetch. -->
    <script src="../vendor/gsap.min.js"></script>
    <style>
      body { margin: 0; background: #111; }
      #root { position: relative; width: 1080px; height: 1920px; overflow: hidden; }
      .clip { position: absolute; inset: 0; display: grid; place-items: center; }
    </style>
  </head>
  <body>
    <div id="root" data-composition-id="test-scene" data-width="1080" data-height="1920" data-duration="3">
      <section id="title-card" class="clip" data-start="0" data-duration="3" data-track-index="1">
        <h1 id="title" style="color:white;font-family:sans-serif;font-size:64px;">Scene title</h1>
      </section>
      <!-- SFX example: <audio src="../sounds/Click.mp3" data-start="1.2" data-duration="0.6" data-track-index="10" data-volume="0.35"></audio> -->
    </div>
    <script>
      window.__timelines = window.__timelines || {};
      const tl = gsap.timeline({paused: true});

      window.__timelines['test-scene'] = tl;
    </script>
